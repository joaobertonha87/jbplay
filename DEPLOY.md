# JB Treinos Pro v3 — IA Online

## Estrutura
- `public/`: PWA
- `server.js`: backend seguro para a IA
- `.env.example`: configuração de ambiente

## Rodar
1. Instale Node.js 20+.
2. Execute `npm install`.
3. Crie `.env` copiando `.env.example`.
4. Preencha `OPENAI_API_KEY`.
5. Execute `npm start`.
6. Hospede o projeto em um serviço HTTPS com suporte a Node.js.

Nunca coloque a chave da OpenAI dentro do HTML, JavaScript do navegador ou PWA.
